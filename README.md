# Afrika Client

A custom Minecraft launcher designed for advanced multi-account management, performance optimization, and custom aesthetic integrations. 

## 🚀 Key Features

* **Multi-Account Profile Manager:** Seamlessly manage and toggle between up to 4+ Microsoft/Minecraft alternative accounts simultaneously from a single hub.
* **Modern Version Orchestration:** Full native support for running isolated modern modded instances (Fabric, Iris, Lithium) across modern game versions.
* **Integrated Media UI:** Built-in Spotify dashboard widget to control and display active music playback seamlessly within the launcher console.
* **Custom Cosmetics Sandbox:** Support for live 3D character skin rendering, wing cosmetics, and custom UI space backgrounds.

## 🛠️ Built With

* [Fabric Project](https://fabricmc.net) - High-performance lightweight modding toolchain.
* [Minecraft Identity Platform](https://microsoft.com) - Secure Microsoft OAuth 2.0 integration for account authentication.
